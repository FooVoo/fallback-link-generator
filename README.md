# fallback-link-generator

A SvelteKit application deployed on Vercel.

## Developing

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

## Building

```bash
npm run build
```

## Deploying to Vercel

This project uses [`@sveltejs/adapter-vercel`](https://svelte.dev/docs/kit/adapter-vercel). Push to your connected Vercel project or run:

```bash
vercel deploy
```
